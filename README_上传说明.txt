解压与上传
1. 在电脑上解压此ZIP。
2. 将解压后的全部文件和文件夹一起上传至GitHub仓库根目录，确保index.html直接位于仓库根目录。
3. 不要只上传ZIP文件，也不要把assets文件夹中的文件拆散；保留现有目录结构。
4. 若需要网页链接，在仓库中启用GitHub Pages，并选择包含index.html的分支和根目录作为发布位置。
5. 本网页为静态网页，无需安装依赖或运行构建命令。

包内内容
index.html：网页入口，包含页面样式、交互脚本和图表绘制逻辑。
assets/：网页需要的图片、视频、字体、公司Logo及字体许可。
data/：图表数据、数据来源及核查记录。
.nojekyll：静态托管标记文件。
