# Naive AI 战略研究

在线阅读：**https://biyihan2005.github.io/naiveai-strategy-research/**

Naive AI 战略研究展示网页，汇报人：毕漪涵，报告日期：2026 年 11 月 3 日。

## 使用

直接访问上方链接即可，无需登录或安装软件。网页使用本地图片、字体、视频和内嵌图表数据，无需后端或 API 密钥。

本地预览：在仓库根目录运行 `python3 -m http.server 8000`，然后打开 `http://localhost:8000`。

## 文件

- `index.html`：页面、样式与交互脚本。
- `assets/`：图片、视频、字体及品牌图形。
- `data/`：图表数据、来源与核查记录。
- `.nojekyll`：GitHub Pages 静态托管标记。

## 部署与更新

通过 GitHub Pages 发布，来源为 `main` 分支的根目录。更新文件并推送到 `main` 后，GitHub 自动重新发布。
